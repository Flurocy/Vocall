# hotkey 主动唤出实现计划（全局快捷键 + 游戏式按键绑定）

日期：2026-07-28
分支：feat/v1-popup-tray，BASE 9e5dd76（完善背单词完成态）
背景：用户后续功能顺序 ①（定 hotkey→回收站→读音）。用户原始需求（2026-07-27）："主动触发 hotkey，游戏式按键绑定，点绑定后按任意键绑定，Esc=空"。

## 用户决策（已确认）
- **默认快捷键** `Ctrl+Shift+W`，可在设置里改。
- **唤出内容**：到期词优先（`getDueVocab`），无到期词则从 **learning+review** 词中**随机抽一个**（跳过 new/mastered）。
- **算入 popCount**：hotkey 唤出与定时弹窗一致，`incrementPop()`（统一逻辑、推动到期队列节奏）。
- **Esc = 空**：绑定态按 Esc → 写入空字符串 → 等于**禁用快捷键**（不注册 globalShortcut）。
- **注销**：`will-quit` 时 `globalShortcut.unregisterAll()`。

## 技术依据（WebSearch 已确认）
- Electron `globalShortcut.register(accelerator, cb)` / `unregister(accelerator)` / `unregisterAll()`。
- 必须在 `app.whenReady()` 之后注册；在 `will-quit`（不是 before-quit）里注销。
- accelerator 字符串格式：`CommandOrControl+Shift+W` 等（Ctrl 用 `CommandOrControl` 跨平台）。
- **按键捕获**：`webContents.on('before-input-event', (e, input) => {...})`，input 有 `key`(如 'a'/'Escape'/'Tab')、`code`、`control`/`shift`/`alt`/`meta` 布尔。拦截后组装 accelerator 字符串。

## 全局约束（精确值，子代理逐字遵守）

1. **新增设置键** `popup_hotkey`（字符串）：accelerator 字符串，如 `CommandOrControl+Shift+W`；**空字符串 = 禁用**（不注册）。
2. **默认值** `popup_hotkey: 'CommandOrControl+Shift+W'`（DEFAULT_SETTINGS 加）。
3. **唤出逻辑封装**：新增 `popupNow(getPopup)`——
   - `const due = getDueVocab()`；有则弹 `due`。
   - 无则从 `listVocab()` 过滤 `status==='learning'||status==='review'`，随机取一个（`Math.random()` 选下标）；为空则不弹（静默 return）。
   - 拿到词后：`incrementPop()` + `showPopup(win, word)`（与 engine.tick 的有词分支**完全一致**，但不排 setTimeout——hotkey 不接管定时循环）。
4. **注册/注销**：新增 `src/main/hotkey.ts`——
   - `registerHotkey(getPopup)`：读 `popup_hotkey`，空则不注册；非空则 `globalShortcut.register(acc, () => popupNow(getPopup))`。注册失败（返回 false，如与系统冲突）`console.warn` 不抛。
   - `reregisterHotkey(getPopup)`：先 `unregisterAll()` 再 `registerHotkey(getPopup)`（设置改后重新绑定）。
   - `app.on('will-quit', () => globalShortcut.unregisterAll())`（在 hotkey.ts 模块级注册该监听，或 index.ts 调用导出的 unregister）。
5. **index.ts whenReady**：启动时调 `registerHotkey(getPopup)`（在 createPopupWindow 之后，确保弹窗已建）。
6. **设置改后重绑**：`setSetting` 当 key==='popup_hotkey' 时，触发 reregister（IPC 层 `settings:set` handler 里判断；或前端保存后额外调一个 `hotkey:refresh` IPC）。**推荐**：IPC `settings:set` handler 在写入后，若 key==='popup_hotkey' 则 reregister——集中、前端不用管。
7. **按键绑定 UI（设置页新增"快捷键"卡片）**：
   - 显示当前 accelerator 的可读形式（`CommandOrControl` → `Ctrl`，`+` → `+`）。空则显示"未设置（已禁用）"。
   - 「绑定」按钮 → 进入监听态：按钮文案变"按下组合键…（Esc 取消）"，渲染端用 `keydown` 监听**一次**，把 event 转成 accelerator 字符串，保存。
   - **Esc**：监听到 Escape → 保存**空字符串**（禁用）+ 提示"已禁用快捷键"。
   - 渲染端 keydown 转 accelerator：修饰键用 `Control`/`Shift`/`Alt`/`Meta`(event.ctrlKey/shiftKey/altKey/metaKey)，主键用 `event.key`（大写，字母转大写；特殊键 Escape/Tab 等排除——Esc 走禁用分支，其他特殊键忽略不算合法组合）。**为跨平台统一，Ctrl 写成 `CommandOrControl`**。
   - 注意：渲染端 keydown 拿不到原始键就够用（无需 before-input-event，那是主进程拦截用）；设置页绑定用渲染端 keydown 最简单。
   - 「重置默认」小按钮：写回 `CommandOrControl+Shift+W`。
8. **不改**：engine.ts 定时循环、scheduler.ts、popup.ts 的 showPopup 签名（复用）、VocabItem/SrsState 结构。

## 包划分

### 包1 主进程（hotkey 核心 + 设置联动）
文件：`src/main/hotkey.ts`(新)、`src/main/index.ts`、`src/main/settings.ts`(DEFAULT_SETTINGS)、`src/main/ipc.ts`(settings:set 联动 reregister)、`tests/`

1. `hotkey.ts`：
   - `popupNow(getPopup)`：到期优先 → 否则 learning+review 随机 → incrementPop + showPopup。
   - `registerHotkey(getPopup)`/`reregisterHotkey(getPopup)`/`unregisterAllHotkeys()`。
   - 模块级 `app.on('will-quit', unregisterAll)`。
2. `settings.ts`：DEFAULT_SETTINGS 加 `popup_hotkey: 'CommandOrControl+Shift+W'`。
3. `index.ts`：whenReady 里 createPopupWindow 后调 `registerHotkey(getPopup)`；import hotkey。
4. `ipc.ts`：`settings:set` handler 写入后，`if (key === 'popup_hotkey') reregisterHotkey(getPopupRef())`——需能拿到 getPopup，方案：把 popup 引用通过参数/模块级传入（index.ts 已有 popupWin，可让 registerIpc 接收 getPopup）。
5. 测试（TDD）：`popupNow` 到期优先逻辑、无到期时随机范围（只含 learning/review，跳过 new/mastered，空则不弹）。globalShortcut 注册本身（需 Electron 运行时）不测，靠真机。
6. `npm test` 绿 + `npm run build` 过。

### 包2 前端（设置页快捷键卡片）
文件：`src/renderer/manager/views/SettingsView.tsx`

1. 新增"快捷键"卡片：显示当前 accelerator 可读形式 +「绑定」+「重置默认」。
2. 绑定态：keydown 监听一次，转 accelerator 字符串保存；Esc → 空字符串（禁用）+ 提示。
3. accelerator 可读化：`CommandOrControl`→`Ctrl` 展示。
4. `npm run build` 过。
