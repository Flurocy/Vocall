# Tasymize 背词形式修订案（V1 → V1.1）

> 日期：2026-07-21
> 触发：用户真机运行 V1 后提出 4 个反馈，其中 2 个动摇产品核心（背什么、怎么背）。经讨论与调研后定案。

## 一、为什么改版（用户的 4 个真机反馈）

1. **弹窗透明+黑字，在深色背景（VSCode）下看不清** → 弹窗底板不能全透明，要可读底色（后续接主题色）。
2. **背词内容形式不对** → 现有"普通词→高级替换"（表达升级块）不是用户想要的"背单词"。
3. **弹窗不可拖拽** → 整个悬浮窗应可拖拽；后续设置要 font size 和 GUI scale。
4. **交互形式不合理** → "回想时间"（自动延时翻答案）剥夺了用户主动权，应参考主流背词软件（用户点名"不背单词"）改为**主动翻卡**。

## 二、核心认知：两个功能分离（用户的关键洞察）

| | 练什么 | 解决什么 | 归属 |
|---|---|---|---|
| **弹窗背词**（本修订案） | 拓展**雅思词汇量** | 输入端：看不懂、听到不知是啥（阅读+听力） | 传统背生词 |
| **句子优化**（V2 功能） | 锻炼**表达能力** | 输出端：说得简单、语法错、质量低（写作+口语） | 输入句子→AI 优化高级表达 |

**结论**：现有"表达升级块"混错了地方——它本该属于 V2 的"句子优化"。弹窗背词回归"老老实实背雅思生词"。旧的 12 条升级对种子数据**直接废弃**。

## 三、新方向

### 背什么：雅思生词卡
```
{ word, meaning, example(可展开), topic, source }
```
- 不要音标（用户明确）
- 例句可展开（默认收起，点开看）
- 词汇来源：雅思核心高频词（防"看不懂、听不懂"）

### 怎么背：翻卡自评（效仿"不背单词"的主动精神，适配弹窗碎片场景）
```
先看单词（想意思） → 用户主动点开 → 显示释义 + 可展开例句 → 自评[忘了/模糊/认识]
```
- **去掉"回想时间"自动翻**（主动权还给用户）
- 交互选 **方案 A（翻卡自评，轻量）**，不做选项测试（弹窗太重）
- **融入"不背单词"的"连续答对 N 次才算过关"机制**进 SRS（现在点一次"记得"就过关太容易）

### 调研依据
"不背单词"核心机制：选项测试防"骗自己"、连续答对 3-4 次才过关、真实语境例句、多主题色+简洁现代界面。弹窗场景取其"主动检验 + 连续答对过关 + 可展开例句"之魂，弃其"10词一组+拼写默写"之重。
（来源：不背单词官网、少数派/掘金评测、墨墨vs不背单词竞品分析）

## 四、数据模型重构

| 旧（Expression） | 新（VocabItem） |
|---|---|
| plain（普通词） | **word**（生词） |
| advanced（高级替换） | **meaning**（释义） |
| example | example（不变，可展开） |
| topic | topic（不变） |
| source / created_at / id | 不变 |

- 类型：`Expression` → `VocabItem`；`NewExpression` → `NewVocabItem`
- 函数：`addExpression/listExpressions/updateExpression/deleteExpression` → `addVocab/listVocab/updateVocab/deleteVocab`
- 文件：`expressions.ts` → `vocab.ts`
- IPC 通道：`expr:*` → `vocab:*`
- 说明：一次性彻底重命名，保持语义一致。所有引用点（弹窗 UI、管理界面 UI、scheduler、IPC、测试）机械适配，保证每个任务包完成后项目可编译、测试通过。

## 五、四个任务包（执行顺序）

- **包1 内容重构**：数据模型改 VocabItem + 所有引用点机械适配 + 种子数据换成雅思生词（AI 生成 ~50 个）+ 测试更新
- **包2 弹窗改版**：主动翻卡（去自动延时）+ 可展开例句 + 可读底板（去全透明）+ 整窗可拖拽 + 自评（连 SRS 连续答对 N 次过关）
- **包3 设置与主题**：设置项调整（去回想时间、加"过关所需连续答对次数"、字体大小、GUI 缩放）+ 主题色切换（弹窗+管理界面）
- **包4 收尾**：托盘 + 开机自启 + 退出入口（原 Task 10）+ 管理界面适配新模型 + UI 美化（现代化简洁风，主题色可切换）

## 六、种子数据方案
用 AI 生成一份高质量雅思核心生词表（首批 ~50 个），每条含 word/meaning/example/topic，覆盖雅思高频话题（教育/科技/环境/社会/政府/健康等）。生成后用户过一批、确认质量再入库。

## 七、UI/交互新增（纳入包2/包3）
- 弹窗可读底板（去全透明，跟主题色）
- 整窗可拖拽
- 主题色切换（设置里选，像浏览器换主题）
- 字体大小 + GUI 缩放设置
- 设计基调：**现代化简洁**（用户明确偏好；避免 frontend-design 易跑偏的古风/文艺风）

## 八、不变的部分（复用）
Electron 骨架、数据层机制（electron-store）、SRS 算法核心（SM-2 变体）、调度引擎、IPC 桥、弹窗窗口框架（frameless/置顶/不抢焦点）、管理界面框架。
